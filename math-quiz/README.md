# 小学生四则运算练习

每次出一道题：三个数字、两个符号。你可以自己选择加减乘除。

规则：

- 最终结果必须是正整数
- 中间每一步也必须是正整数
- 除法必须整除
- 先算乘除，再算加减

## 使用

在终端运行：

```powershell
cd "E:\我的项目\math-quiz"
python -m math_quiz
```

按提示选择运算：

```
1. 加法 +
2. 减法 -
3. 乘法 ×
4. 除法 ÷
```

可以只选一种，也可以多选，例如输入 `1 2` 就是加减混合。

也可以直接指定参数：

```powershell
python -m math_quiz --ops +-* --count 10
```
