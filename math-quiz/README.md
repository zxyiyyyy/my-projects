# 小学生四则运算练习

每次出题：两个或三个数字、一到两个符号。你可以自己选择加减乘除。

规则：

- 答案在 0~100 之间的整数
- 中间每一步也必须是 0~100 的整数
- 除法必须整除，不会出现 ÷1，也不会出现自己除以自己
- 先算乘除，再算加减
- 可选小括号，括号内的算式必须是正整数（可以含加减乘除）
- 数字大小分档：纯加减可到 80，含乘除在 20 以内，纯除法到 100
- 同一份练习里的题目不重复

## 网页版

浏览器打开 `web/index.html` 即可练习，支持在线出题、可选小括号、自动判分、错题回顾。

## 使用

在终端运行：

```powershell
cd "E:\我的项目\math-quiz"
python -m math_quiz
```

按提示选择运算：

```
1. 加法 +
2. 减法 -
3. 乘法 ×
4. 除法 ÷
```

可以只选一种，也可以多选，例如输入 `1 2` 就是加减混合。

也可以直接指定参数：

```powershell
python -m math_quiz --ops +-* --count 10
```
